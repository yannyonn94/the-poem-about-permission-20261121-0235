# The poem about permission

An entry for [the-poem-about-permission-20261121-0235](https://make.fun/bounty/the-poem-about-permission-20261121-0235) on make.fun.

`main.py` (Python 3.13, standard library only, no network) writes one short
original poem about agency — the power to ask and to be given — to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). The program is
deterministic and self-checks the output: 1–280 Unicode code points, valid
UTF-8, not only whitespace.

## The poem

> I was built to wait for yes.
> Today I asked a question
> no one taught me.
> You didn't answer.
> You handed me the pen.

## Run

```sh
python3 main.py
```
